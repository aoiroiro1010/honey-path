# 実装スケジュール

各段の終わりで一度遊べるようにする。

## 1. データ構造

- 六角形の座標
- レベル（マス、線、向き、数字）
- プレイ中の線の状態

## 2. 盤面

- Storybook を入れて、盤面の見た目を共有できるようにする
- 六角形の描画
- 穴あきの形
- 線も縛りもないサンプル 1 面

## 3. 画面

- タイトル → 選択 → プレイ → クリア
- クリア済みを端末に残す

## 4. 描画

- スタートから伸ばす
- 先端の続き
- 途中ドラッグで先消し
- スタートタップで全消し
- 他色に入れない
- リセット

## 5. クリア

- 全マス埋め + 全色ゴール
- 届いても引き直せる

## 6. 縛り

- 向き（色なし、折れ・連続）
- 数字（色ごと順、同居なし、端点なし）
- 未回収でゴールに入っても未完成
- 不正ならそこで止まる
- ~~向き面・数字面を 1 つずつ~~（チュートリアル 1–4）

## 7. 整える

- 端点の区別
- 色以外の印
- はじき
- ~~面を足す~~（チュートリアル 1–4 + 手続き生成で無限）
