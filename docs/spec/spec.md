# Honey Path

六角形のマスを、色の違う線で埋め尽くす一筆書き。

## ルール

- 色ごとにスタートとゴールがある
- 交差・分岐なし。隣のマスへ一筆でつなぐ
- 全マスを埋め、各色が数字を順に拾ってゴールに届いたらクリア
- ゴールに入っても、数字が残っていればその色は未完成
- 縛りがあるマスはそれに従う
  - **向き** — 色は問わない。通り方が決まっている。直線・折れ・複数マス続き可。通るならその形どおり
  - **数字** — 色ごとの番号を 1 から順に拾う

## 盤面

- とんがりが上の六角形
- 形はレベル次第。欠けていてもよい
- 1 マスに線は 1 本だけ
- スタート・ゴールに、向きや数字は置かない
- 向きと数字は同じマスに置けない

## 操作

- スタートからだけドラッグして伸ばす。ゴールからは描かない
- 途中まで書いてあれば、先端から続きを描ける
- 書いた線の途中からドラッグすると、そこより先を消して新しい続きを描く（ゴール後も同じ）
- スタートをタップすると、その色を全部消す
- 向きが合わない・数字が飛ぶ・他色のマスでは、そこで止まる。線は消えない
- リセットのみ。戻すはなし

## 画面

- タイトル → レベル選択 → プレイ → クリア
- クリアしたレベルは端末に残す
