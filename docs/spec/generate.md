# 高難易度の問題の生成方法

# 1 正解の経路を作る

1本の大きな経路をつくるのではなく、色の数だけそれぞれ別の経路にする。
難易度が上がるほど色数を増やす。**高難易度では 6 色を使う。**

難しくするコツ

- スタートとゴールが直線で結んだ時クロスするような関係
- 線がおおきく曲がっていて色の異なる線が隣接している。

# 2 解が一意に定まるようなものにする。

- すべての空きマス（端点以外）に向きを追加する → 別解が全くない状態
- そこから向きを減らしていき、別解が出てこないギリギリまで減らす
  （削除する向き・順番を変えて何度も探索し、より少ない向きを採用する）
- 残った向きの多少は問わない。多すぎても盤を捨てて 1 に戻ったりはしない

# 3 番号を追加

番号を追加することで、難易度は下がる。
高難易度にするためには、番号は入れない。
