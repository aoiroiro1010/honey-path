colorCount:ほどほどに
holeCount:増やすと簡単
numbersPerColor:増やすと簡単


# むずいバランス

radius:1,hole:0に対し
color:1がむずい
number:1くらいがちょうどいい

radius:5,hole:0に対し

番号の位置は以下のように配置。
- スタートからゴールへの開いてるマスを数える
- その中から、なるべく均等な間隔になるよう配置

# 難易度の上昇

チュートリアル
1. スタートからゴールまで線を引くだけ
2. 色ごとに別々の線を引く
3. 向きの印
4. 番号

だんだんと難易度が上昇
